Tu rutina de actualización

Del ordenador a la web publicada

El Gestor prepara los archivos. GitHub Desktop los sube. GitHub Actions publica la nueva versión automáticamente.

1

Termina los cambios

Si usaste el Gestor, pulsa «Construir y preparar». Si programaste, guarda los archivos y ejecuta las pruebas.

2

GitHub Desktop

Abre Atlas → pestaña Changes → revisa los cambios → escribe un resumen → Commit to main/master.

3

Subir

Pulsa Push origin. Si aparece «Fetch origin», púlsalo primero y vuelve a comprobar los cambios.

4

GitHub web

Repositorio → Actions → «Construir y publicar Atlas» → espera el círculo verde. No hace falta tocar Pages otra vez.

5

Usuarios

Abren Atlas y pulsan «Actualizar Atlas» o recargan. El Service Worker descarga la versión recién publicada.

ImportanteNi «Preparar dist» ni guardar contenidos los hace públicos. La actualización llega al público solamente después de Commit → Push origin → Action verde.
